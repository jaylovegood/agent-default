# Task Plans

Create a plan only for work that is complex, risky, multi-session, or likely to move between tools.

- Put current plans in `docs/plans/active/`.
- Start from `docs/plans/template.md`.
- Use one plan per coherent outcome.
- Keep plans concise and evidence-based.
- Remove or archive a completed plan only when the user or project workflow calls for it.
- Do not store raw chat transcripts or large command logs here.
